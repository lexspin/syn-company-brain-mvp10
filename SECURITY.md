# Security

The hosted edition is a static presentation: it has no account login, model execution, private backend or connection to the founder's computer. Framework modules are development-stage source; a secure hosted agent service requires separate authentication, isolation, secrets management and operational review.

For a suspected vulnerability, use [private vulnerability reporting](https://github.com/lexspin/syn-company-brain-mvp10/security/advisories/new). If unavailable, contact the maintainer through GitHub before sharing exploit details or sensitive data publicly. No response-time guarantee is offered. General hardening proposals without sensitive details can use an issue.

Use synthetic data in examples. Do not run retained host-integration modules against private workspaces without inspecting their assumptions. Do not expose local development servers to the internet. No security audit here establishes the absence of vulnerabilities.
