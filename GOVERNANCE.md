# Governance

This is a maintainer-led research framework. Alex Rada (GitHub: lexspin) maintains the project. Anyone may propose code changes, documentation edits, research corrections and roadmap issues. Maintainers review scope, evidence, compatibility, licensing and privacy before merging. Contributors retain the right to fork under the licence.

Changes to architecture, public protocols or release commitments should start with an issue stating the problem, alternatives, assumptions and acceptance evidence. An agreed project convention is not an industry standard. Public releases use version tags; MVP10 identifies the originating presentation edition, not a production service-level guarantee.
